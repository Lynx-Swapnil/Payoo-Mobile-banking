# 💰 Payoo - Mobile Financial Service

A fully functional full-stack mobile financial service (MFS) web application.

---

## 🌐 **LIVE DEMO**

### 👉 [**Click Here to Visit Live Site**](https://payoo-mobile-banking-1.onrender.com)

---

## ✨ Features

- **User Authentication** - Secure JWT-based registration and login
- **Add Money** - Fund your account from multiple banks
- **Cashout** - Withdraw with automatic 1.5% charge calculation
- **Transfer Money** - Send money to other users instantly
- **Get Bonus** - Redeem coupon codes for free money
- **Pay Bills** - Pay utility bills (Electricity, Water, Gas, Internet, Mobile)
- **Transaction History** - View all your transactions with beautiful UI

---

## 🎯 How to Use

1. **Visit:** [https://payoo-mobile-banking-1.onrender.com](https://payoo-mobile-banking-1.onrender.com)
2. **Register:** Enter any 11-digit phone number and create a 4-digit PIN
3. **Start:** You'll get $1234.56 starting balance!
4. **Explore:** Try all features - add money, transfer, use bonus coupons!

## 🛠️ Tech Stack

**Frontend:** HTML5, Tailwind CSS, DaisyUI, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** JSON-based storage  
**Authentication:** JWT + bcrypt  
**Hosting:** Render.com (Frontend + Backend)

## 💻 Local Development

Want to run this locally?

### Quick Start:
```bash
# Clone the repository
git clone https://github.com/Lynx-Swapnil/Payoo-Mobile-banking.git
cd Payoo-Mobile-banking

# Install backend dependencies
cd server
npm install

# Set up environment variables
copy .env.example .env
# Edit .env and add your JWT_SECRET

# Start both servers (from project root)
# Option 1: Double-click start.bat (Windows)
# Option 2: Run npm start
cd ..
npm install
npm start
```

**Servers will run on:**
- Frontend: `http://localhost:8000`
- Backend: `http://localhost:3000`
